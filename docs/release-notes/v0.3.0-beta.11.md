Goal forecasts that add up.

Update with `update` inside the container (or `pct exec <id> -- update` from the Proxmox host).

## Fixes

- **A goal started recently showed "Behind" with a pace far too low.** The pace was averaged over the last three months even when saving had only just started, so 37,50 € put aside this month counted as 12,50 €/month. It now counts only the months since saving started. A goal that has received this month's share is "On track" and finishes on its date.
- The last two dates on goal charts could overlap ("08/202610/2026"). Charts now leave room for the labels.
