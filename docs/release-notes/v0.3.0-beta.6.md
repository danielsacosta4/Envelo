No more old code after an update.

Update with `update` inside the container (or `pct exec <id> -- update` from the Proxmox host).

## Fixes

- After an update, a browser or reverse proxy could keep serving the previous app.js next to the new page, so new buttons (like **Delete transactions**) did nothing. Script and style links now carry a fingerprint of the file, so each update loads fresh files, and the page itself is never cached.
- When Envelo is updated while a page is open, a banner offers to reload instead of running the old version.
