Security hardening, following a full review of the server, the app and the installers.

Update with `update` inside the container (or `pct exec <id> -- update` from the Proxmox host). **Read "After updating" below.**

## After updating

- **Sign-up is now invite-only.** Your account keeps working. To let someone in, invite them in **Settings → Invite someone**, or share envelopes with them (that invites them too). On the server: `envelo invite <email>`, and `envelo registration open|invite|closed` to change the mode.
- **`TRUST_PROXY=1` is added to `/etc/envelo/envelo.env`.** Envelo then knows each visitor's real address from your reverse proxy (needed for the new sign-in limits) and marks cookies secure over HTTPS. If browsers reach Envelo directly, without a proxy, set it to `0` and restart (`systemctl restart envelo`).
- **Two-step sign-in now asks for your password** before it can be turned on.
- **Back up `/etc/envelo/secret.key`** somewhere safe: the data cannot be read without it.

## Fixed

- **Password guessing:** sign-in attempts are limited per account and per address. A successful sign-in to another account no longer resets the count. The same limits cover two-step codes and every password check inside the app.
- **Everyone locked out behind a proxy:** a few wrong passwords from anyone could lock everyone out for 15 minutes. Fixed with `TRUST_PROXY`.
- **Open sign-up:** strangers could create accounts and fill the disk. Sign-up is now invite-only, and photos and PDFs are limited to 200 MB per person. Unused old attachment files are cleaned up.
- **Oversized import files:** a specially built Actual import file ("zip bomb") could use up the server's memory. It is now refused.
- **Requests from other sites:** writes must come from Envelo's own pages.
- **Two-step sign-in:** turning it on or off signs out your other devices, and needs your password. New **Sign out everywhere else** in Settings.
- **Live updates** stop when a session ends, and the number of open streams is limited.
- **Shared envelopes:** adding spending or money can no longer save over newer changes by the owner, and amounts and dates are checked.
- **Shared computers:** signing out clears what the browser cached for Envelo. Signing out while offline now says it did not work, instead of pretending.
- **Encrypted data:** each encrypted file is now bound to what it is, so files cannot be swapped between people. A plain-text database is refused once the data has been encrypted.
- **Passwords:** stored with a stronger hash, upgraded at your next sign-in, and computed without stalling the server. Recovery codes are salted.
- **Internal names:** the app escapes every internal name it puts on a page.
- **Installer and `update`:**
  - settings are read as plain values instead of being run as shell code;
  - the GitHub token for private repositories is no longer visible to the web server or in the process list;
  - the service runs with more restrictions, which turn themselves off if the container does not support them;
  - folders are private;
  - new installs no longer log in to the console as root automatically (opt-in in the Advanced menu).
- **Smaller things:** error messages no longer reveal internals, leftover import files are removed at start, and HSTS is sent over HTTPS.
