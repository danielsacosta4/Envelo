Manage payees.

Update with `update` inside the container (or `pct exec <id> -- update` from the Proxmox host).

## New: Payees page

Under **Payees** (in **More** on a phone) every payee is listed with how often it is used, the total, its usual envelope and the last date.

- **Rename** a payee on every transaction at once.
- **Merge** payees: tick two or more (for example "Pingo Doce" and "PINGO DOCE LISBOA") and merge them into one name.
- **Rules**: "when the payee contains (or is) this text, rename it to this and put the spending in this envelope". Rules run on every bank import, and can be applied to what is already there. Applying a rule only gives envelopes to spending that has none yet ("To categorise"); spending you already categorised keeps its envelope.
- Click a payee to see all of its transactions.

A rule's envelope also wins over "last used" when you type the payee in a new transaction.
