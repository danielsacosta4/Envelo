**Security update: install it now.**

Update with `update` inside the container (or `pct exec <id> -- update` from the Proxmox host).

## Fixed

- **Critical: account takeover.** A specially crafted budget, saved by anyone with an account on the same Envelo, could make the server accept a made-up sign-in for any other account, without its password or two-step code. The server now refuses budgets with unsafe property names, IDs or values. Its sign-in and account lookups can no longer be tricked this way.
- Budgets from outside (backup files, shared envelopes) are checked the same way in the browser. Names and IDs that could have broken out of the page's HTML are refused.

More security hardening (sign-in limits behind a reverse proxy, invite-only sign-up and more) follows in the next update.
