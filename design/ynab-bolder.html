Envelo: YNAB, bolder

Five directions built on YNAB's structure: accounts, categories, Budgeted, Spent, Available, and a Ready to Assign block. Each one pushes the look harder in a different way. Sample October data, EUR.

1. Colour-blocked groups

Each category group gets its own full-width colour band. The budget reads like a set of zones, not a list.
